# 基金 & 股票 云端监控

电脑关机也能看：数据由 GitHub Actions 每 15 分钟自动抓取，GitHub Pages 免费托管，手机/电脑任何网络打开下面的网址即可查看：

**访问地址：** `https://<你的GitHub用户名>.github.io/<仓库名>/`

## 修改关注的基金 / 股票

编辑 `fetch.py` 顶部的 `FUNDS` 和 `STOCKS` 列表：

```python
FUNDS = [
    {"code": "001480", "name": "财通成长优选混合A"},   # 基金代码 + 名称
]
STOCKS = [
    {"code": "sz000001", "name": "平安银行"},          # 股票代码（sh/sz 前缀）+ 名称
]
```

修改后保存，GitHub 会自动重新部署（1-2 分钟生效）。

## 功能
- 📈 基金：实时估值/净值 + 120 日走势 + 明日预测
- 📊 股票：实时行情 + 日K线（120 日）
- 📰 大盘指数 + 财经新闻（重点热闻自动高亮）
- 每 15 分钟自动更新（GitHub Actions 免费额度）
